# LightPrompt — an AI wellness platform I built and run

**What it is:** A self-reflection and wellness platform that uses AI as a mirror for personal growth, plus a line of digital products.
**My role:** Founder. I handled product, design, build (using AI-assisted development), content, and launch.

---

## What I built

A full-stack web app:

| Area | Tech |
|---|---|
| Front end | React + TypeScript, Tailwind CSS, Radix UI |
| Back end | Node.js / Express, REST API |
| Data | PostgreSQL (Supabase) with Drizzle ORM, Google Cloud Storage |
| AI | OpenAI GPT-4o with several distinct chat personalities, Whisper voice transcription, text-to-speech, sentiment analysis |
| Payments | Stripe: one-time purchases and subscriptions |
| Hosting | Vercel, Replit |

**Features I designed and shipped**
- Multiple AI companions, each with its own personality and system prompt
- Voice input and spoken replies
- A store with Stripe checkout for courses, ebooks, and bundles
- Free and premium tiers with AI token-usage tracking
- **GeoPrompt:** a location-based concept using NFC-tagged tokens placed around Austin that link to a reflection portal

## Products I shipped alongside it

- ***LightPrompt:Ed: The Human Guide to AI, Soul, and the Future***: a 20-chapter book formatted and published for Amazon KDP paperback
- A 60-card printable oracle deck with AI companion prompts
- A 106-page guided workbook
- A five-version personalized ebook series tied to a quiz
- A typography wall-art bundle

## What this shows

I can take a product from idea to something live: scoping features, designing the experience, building with AI tools, wiring up payments and data, and shipping the content that goes with it. It also gave me hands-on experience with prompt design, AI personalities, and the real costs of running AI features.
