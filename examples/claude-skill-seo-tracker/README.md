# Example: a Claude skill I wrote

A **skill** is a set of instructions Claude follows to do one job the same way every time. This one builds and refreshes the [SEO Keyphrase Tracker](../../case-studies/seo-keyphrase-tracker.md).

What it covers:
- Which data sources to check, and what to do when one is missing or out of credits
- Exact definitions for every metric, so numbers mean the same thing on every run
- The dashboard layout and the recommendations it should make
- How to refresh without breaking history, and how to keep client data private
